# ratchet

Phase-gated SWE workflow for coding agents. A ratchet only turns one way:
forward, through gates, never slipping back to an unreviewed state — that's
the whole idea.

Ships as an installable plugin for both **Claude Code** and **Codex**, from
one skills tree, via the [open agent skills standard](https://agentskills.io).

Status: bootstrapping. See `docs/architecture-decisions/` for the design.
